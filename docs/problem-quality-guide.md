# CodeDuo Problem Quality Guide

문제은행을 수정할 때 각 목차의 3문제 흐름은 아래 기준을 따른다.

## 난이도별 역할

- 초급: 문법과 개념을 빠르게 확인한다. 객관식 위주를 유지하되, 단순 암기보다 자주 헷갈리는 보기를 넣는다.
- 중급: 입력, 연산, 조건, 반복, 자료구조를 실제 상황에 적용한다. 단답형은 용어 확인, 코드형은 작은 기능 구현으로 둔다.
- 고급: 여러 개념을 조합하거나 실수 포인트를 설명하게 한다. 코드형은 예외 케이스가 드러나는 테스트를 포함한다.

## 목차별 3문제 흐름

- 1번: 해당 목차의 핵심 문법을 고른다.
- 2번: 비슷해 보이지만 틀리기 쉬운 문법을 구분한다.
- 3번: 빈칸이나 짧은 코드로 직접 적용한다.

중급과 고급도 같은 흐름을 확장한다.

- 중급 1번: 용어 또는 핵심 함수 이름을 확인한다.
- 중급 2번: 작고 명확한 기능을 구현한다.
- 중급 3번: 같은 개념을 다른 상황에 적용한다.
- 고급 1번: 경계값이나 예외 케이스가 있는 구현 문제를 둔다.
- 고급 2번: 두 개 이상의 개념을 조합한다.
- 고급 3번: 왜 그렇게 동작하는지 설명하게 한다.

## 문항 작성 규칙

- 제목은 `두 수의 합`처럼 추상적으로 쓰기보다 `두 라운드 점수 합산`처럼 상황을 드러낸다.
- 설명은 사용자가 왜 이 코드를 쓰는지 알 수 있게 한 문장으로 맥락을 준다.
- 객관식 오답 보기는 실제 초보자가 고를 법한 실수로 만든다.
- 코드 문제 테스트 케이스는 정상값, 경계값, 음수나 0 같은 실수 포인트를 최소 3개 넣는다.
- `tagsJson`에는 반드시 목차명을 넣어 추천, 분석, 레슨 선택이 같은 기준으로 동작하게 한다.
- 객관식 정답은 import 시 `correctOptionIndex`로 변환되므로 `answer`는 보기 텍스트와 정확히 일치해야 한다.
